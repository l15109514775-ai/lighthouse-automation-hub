使用说明

执行器已托管：成员上传登记后，白名单自动批准、自动执行、自动回传，人工只需听校与审核。

先看这里：身份、密钥和云环境的关系

已有云环境配置可用时，可以继续使用同一个身份，不需要每个视频都新建。只有需要更换身份，或身份已到期、额度用完、密钥丢失时，才需要重新配置。

网页里看到的内容具体用途
云执行身份 / 身份备注网站给字幕程序的授权；备注用于辨认，可自行修改。
创建时显示的身份密钥填入云环境的 SUBTITLE_PLATFORM_TOKEN，让字幕程序领取指定任务、更新进度并回传字幕。
subtitle-delivery-20min-active当前工作流实际运行的 Codex Cloud 环境。身份备注相同，不代表密钥已经配对。

密钥只显示一次，请直接在配置表单中保存，不要发到聊天、QQ 群或放进代码。它是本站执行身份密钥，与翻译、识别服务的 API Key 分开；现有 SUBTITLE_PLATFORM_GATEWAY_KEY 和模型凭据保持原配置。

同一环境中的 SUBTITLE_PLATFORM_TOKEN 一次对应一个身份。更换前先处理完分配给旧身份的未完成任务，避免换完后无法领取旧任务。备注里的 Cloud、60s、20min 都不决定视频时长；上限由每次审批决定，最多 20 分钟。

执行器：已托管，无需配置

执行器已经部署在服务器上，由管理员维护；成员和组长都不需要在 Codex Cloud 或手机端配置任何密钥。

  • 执行器每 5 分钟检查一次待处理申请；
  • 白名单成员的申请自动批准并领取；
  • 开始和完成会私聊申请人和组长；
  • worker key、网关 key、OpenAI/千问/中转站 key 只保存在服务器的 root-only 环境文件中，更换时由管理员修改并重启执行器。

管理员检查：docker logs subtitle-ingest、journalctl -u subtitle-poller；任务状态以站内任务卡为准。

成员端：浏览器上传即可

PC 和安卓都用浏览器操作，不需要安装客户端，也不需要填写任何密钥。

  • 单个视频不超过 20 分钟、1GB；
  • 上传完成后等待自动审批与执行；
  • 执行期间可以关闭页面；完成后回站内下载 ASS/SRT 和报告。
日常字幕流程：登记、自动审批、自动执行、听校
  1. 成员登记并上传。在“字幕申请与审批”填写标题、时间戳并完整上传视频；上传和登记不会调用模型。
  2. 自动审批。白名单内的申请由执行器自动批准；不在白名单的申请仍由组长在网页手动批准。每人每天 2 条、≤40 分钟；全局每天 6 条、≤120 分钟。
  3. 执行器领取。上海节点从 CloudBase 同地域下载素材并只抽取音频，5Mbps 传到硅谷；开始消息私聊申请人和组长。
  4. 自动回传。硅谷节点完成识别（whisper-1 主 + 千问第二意见 + gpt-4o 裁判）、翻译和字幕生成后自动回传，完成消息私聊两人；可在任务卡下载 ASS/SRT 和报告。
  5. 人工听校与验收。AI 初稿仍需成员听校并提交人工版本，再由审核员审核；云端交付本身不产生人工贡献积分。

限额：单条 20 分钟 / 1GB；超额申请会留在待审批，不会偷偷降级或重复扣费。

常见问题：失败、待核对、换密钥
  • 失败：任务卡显示失败原因；执行器日志 docker logs subtitle-ingest；失败不会自动重发已付费请求。
  • 结果待核对：发布结果不确定时任务会停下，不重复发送；组长核对后再处理。
  • 换密钥：修改服务器 /opt/lighthouse-hub/backups/subtitle-runner/env 后重启 subtitle-ingest；worker key 有效期到 2125 年。
  • 自动归档：已批准的申请满 30 天后自动移入“已删除申请”，不删除任何数据，可随时恢复。
  • 素材保留：原视频 7 天后自动清理，字幕与报告继续保留；上海节点在传输完成后立即删除本地副本。
账号、项目、认领、交付、审核与积分
  1. 开通账号：新成员在登录页选择邮箱注册，填写邮箱验证码、组内昵称、用户名及密码。注册后默认无项目权限；组长在“成员管理”的注册申请中选择项目和身份后批准。以后使用用户名和密码登录；邮箱验证码登录作为备用。之前仅用验证码注册的账号不会自动获得密码。
  2. 新建或认领项目：正式组员点击“新建项目”即成为负责人。Codex 发起的项目显示在未认领项目列表，首位认领项目或其中任务的成员成为负责人；释放任务不转移负责人。Codex 字幕初稿归入校对任务。
  3. 发起任务：选择项目，填写任务类型、要求和原素材位置。剪辑/压制交付视频，封面交付图片；翻译/时间轴/校对交付字幕。
  4. 认领与交付：认领任务后，在任务详情按类型上传视频/图片，或提交字幕文本、读取 SRT、ASS、VTT、TXT 文件。每次提交生成新版本和内容摘要。ASS 下载保留原有样式与特效；SRT 可转换下载为 ASS（默认样式），也可下载原 SRT。
  5. Codex 初稿：项目负责人可把 Codex 文本手动导入待认领任务。成员认领后加工并提交人工版本，说明 AI 辅助与自己的实际工作。
  6. 审核与积分：审核员审阅最新版本，退回修改或批准。批准时填写已核验的人工贡献和积分；提交者不能审核自己的交付。
  7. 保留沟通：讨论继续用 QQ 群。在群里 @「字幕助手」发送「菜单」可查看功能；个人任务查询请私聊机器人，并在本站「成员管理 → QQ 账号绑定」完成本人绑定。任务认领、交付和审核继续在本站操作。

组长和项目负责人可删除项目（页面右下角）或任务（任务窗口底部），须输入名称确认。删除进入回收站，可恢复；不会抹除历史贡献或永久清空文件。恢复任务后必要时需重新认领。

视频上限 1GB（1024MB），封面图片上限 20MB。大文件自动分片传输，全部完成才生成交付版本；当前不支持断点续传，失败后需重新上传。下载时请保持本页打开并保持登录。文件会先计算校验，可查看上传进度并取消。原文件存于私有存储，按项目权限访问，预览与下载链接有效期 10 分钟。

忘记密码时，在登录页点击“忘记密码？”，使用已绑定邮箱的验证码重设密码；未绑定邮箱的账号请联系组长核实。重设后用原用户名和新密码登录。
本页刷新后需重新登录。退出本页会清除当前页面会话；不会撤销已经颁发的短期访问令牌。

贡献与积分页面可查看本人跨项目明细；组长可筛选成员及项目，调整已核验贡献积分时必须填写原因。调整新增流水，保留原审核、贡献与积分记录；尚未生成公开履历页。
